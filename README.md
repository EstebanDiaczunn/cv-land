# cv-land

Personal CV site for **Esteban Nicolás Diaczun** — Backend Developer. Static, bilingual (ES/EN), dark-mode minimalist with monospace body type and a ⌘K command palette.

Built with Astro 5, Tailwind CSS v4, and vanilla JS. No React, no CMS, no backend.

## Quickstart

```sh
pnpm install
pnpm dev          # http://localhost:4321
pnpm build        # static output to dist/
pnpm preview
```

Node `>=22.12.0` required. See `CLAUDE.md` for architecture and conventions.
